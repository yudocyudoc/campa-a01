# CEI · campa-a01

Laboratorio público y reproducible de experimentos sobre dinámica de sistemas, generación de hipótesis e identificabilidad.

**Estado:** exploratorio. Las simulaciones y las pruebas de software no demuestran causalidad ni validez en sistemas reales.

## Ramas

- `main`: infraestructura probada y campañas consolidadas.
- `exp/<nombre>`: una rama por campaña; sus resultados entran por pull request.
- `setup/<nombre>`: mantenimiento e infraestructura; entra por pull request.

No se reescribe el historial de experimentos. También se conservan los resultados negativos o inconclusos.

## Antecedentes

- [CEI c0.0](https://github.com/yudocyudoc/c0.0): grafos, hipótesis, pruebas discriminantes, adversarios e identificabilidad.
- [CEI sd-ai-cei](https://github.com/yudocyudoc/sd-ai-cei): experimentos de modelos stock-flow con LLM y validación.
